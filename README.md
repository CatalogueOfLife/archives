# CoL Annual Checklist Archives

## Installation

1. Download the database dumps into the data directory.

2. To build the images run:

```
DATABASE_PASSWORD=pwd_here docker-compose build
```

3. To run the annual checklist archives run:

```
docker-compose up
```
